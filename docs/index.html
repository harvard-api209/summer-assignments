Course stance

Learning statistics with AI

AI is now part of analytical work. That does not make the basics less important. It makes them more important.

These assignments are not about avoiding AI, and they are not about letting AI do the work for you. They are about learning enough R, statistics, and data judgment that AI can be useful without becoming a crutch.

  • Try the code yourself first.
  • Run any AI-suggested code before trusting it.
  • Check that column names, filters, and denominators are correct.
  • Explain the output in your own words.
01

You should understand every line of code you submit.

02

You should be able to explain every table or graph you produce.

03

You should check AI suggestions against the actual data.

04

You should document meaningful AI help when it changes your work.

05

You should treat missing data, units of analysis, filters, and denominators as statistical responsibilities, not technical details.
