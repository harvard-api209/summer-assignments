The process

Move through the assignments in order. Each part builds the habits you will use during Math Camp and API-209: inspect data, write code, filter coherently, check output, and explain what the result means without overclaiming causality.

01

Save your own copy

Open the Posit Cloud project and save a permanent copy to your workspace before editing any assignment files.

02

Work in the R Markdown file

Open the relevant assignment in the assignments folder. Write code and short answers directly in the notebook.

03

Knit early and often

Knit the notebook regularly. Knitting runs the file from top to bottom in a fresh R session and confirms the document is reproducible.

04

Submit the Rmd

Submit the completed .Rmd file to Canvas using the course submission instructions.

Course stance

Learning statistics with AI

AI is now part of analytical work. That does not make the basics less important. It makes them more important.

These assignments are not about avoiding AI, and they are not about letting AI do the work for you. They are about learning enough R, statistics, and data judgment that AI can be useful without becoming a crutch.

A good analyst does not simply ask a tool to analyze the data and accept what comes back. A good analyst defines the question, checks the data, chooses the method, verifies the output, documents the choices, and knows when something does not make sense.

01

You should understand every line of code you submit.

02

You should be able to explain every table or graph you produce.

03

You should check AI suggestions against the actual data.

04

You should document meaningful AI help when it changes your work.

05

You should treat missing data, units of analysis, filters, and denominators as statistical responsibilities, not technical details.

Course data

One cleaned development snapshot

The five assignments use the same local CSV: data/development_indicators_2026.csv. Each row is one country or economy in one year. The data dictionary data/development_indicators_dictionary_2026.csv explains each variable, source, unit, and caveat.

Most indicators come from the World Bank World Development Indicators. Governance variables come from the Worldwide Governance Indicators. The teaching team uses a pre-cleaned CSV snapshot so everyone gets the same values and the notebooks knit reliably.

Five parts

Assignment roadmap

Use this roadmap to understand the sequence. To see the actual assignment files, open the Posit Cloud project and check the .Rmd files in the assignments folder.

Part 1

Programming Fundamentals

Learn objects, data types, logical values, functions, vectors, comments, why knitting matters, and how to read one simple error message. Estimated time: 1.5-3 hours.

Part 2

Filtering Country-Year Data

Practice reading the local CSV, using the data dictionary, inspecting valid values, filtering rows, sorting, mutating simple columns, and interpreting missingness. Estimated time: 2-3 hours.

Part 3

Data Visualization

Build descriptive plots with ggplot(), choose geoms and aesthetics, label figures, use facets, and explain whether a graph shows a trend, comparison, or association. Estimated time: 2-3 hours.

Part 4

Data Manipulation II

Use group_by() and summarise(), compare means and medians, check denominators, and treat missing values as a data-quality issue. Estimated time: 2-3 hours.

Part 5

Mini Development Diagnostic Memo

Choose one country and coherent peers, produce a trend plot, comparison table, second output, and short non-causal diagnostic memo. Estimated time: 3-4 hours.

AI use

Debug, verify, explain

AI tools can help explain an error message or remind you what a specific R command does. They should not choose your answer, replace your practice, or write interpretations that you cannot defend. The assignments include short AI-use prompts focused on debugging and verification.

  • Try the code yourself first.
  • Run any AI-suggested code before trusting it.
  • Check that column names, filters, and denominators are correct.
  • Explain the output in your own words.
