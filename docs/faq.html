Working in the browser

Where is my work saved?

Automatically, as you type, in this browser on this device. It survives closing the tab and restarting your computer. Clearing your browser data deletes it, and other browsers or devices cannot see it. The .Rmd you download with the Download my .Rmd button is the durable copy — export whenever you stop working.

I lost my work in the browser — what now?

First check that you are in the same browser, on the same device, and not in a private window — each one has its own storage. If the work is truly gone, open your most recent downloaded .Rmd: your code and answers are in it, and you can paste them back into the page.

Why is the first Run in Parts 2–5 slow?

The first Run downloads R and the tidyverse into your browser — a few minutes, one time. After that, runs are fast. If you prefer, the data-heavy parts also run in Posit Cloud, which is quicker for them.

Is the browser version the same assignment as Posit Cloud?

Yes. Same questions, same dataset, and the exported .Rmd has the same structure — the teaching team grades the same file either way.

Do I need Posit Cloud at all?

Not for the summer. It is an optional alternative if you prefer RStudio — see the Posit Cloud setup page. During Math Camp the teaching team will move everyone to a local RStudio setup.

Posit Cloud: access and setup

I cannot enter Posit Cloud. What should I do?

Open the Posit Cloud project and sign in with a Google, GitHub, or Clever account. We recommend Google for simplicity; a Harvard email that uses Google sign-in should also work. After you enter the project, save a permanent copy so it appears in your own workspace.

After your copy opens, use the Files pane in the lower-right corner to open the assignments folder. The five assignment .Rmd files are inside that folder.

Do I need to install R or RStudio?

No — Posit Cloud runs RStudio in your browser and is the supported default. During Math Camp, the teaching team will help everyone move to a local R/RStudio setup.

If you prefer to work locally now (or your internet connection makes a cloud editor painful), you can: install R and RStudio Desktop from posit.co/download, download the course materials as a zip file, unzip it, and open the .Rmd files in the assignments folder. The folder structure and file paths are identical to the Posit Cloud project. Submission is the same either way: upload the completed .Rmd files to Canvas.

Can I rename my Posit Cloud project?

Yes. Renaming your personal copy can make it easier to find later in your workspace. Do not rename the individual assignment .Rmd files until you are downloading them for submission.

Why can I not find the work I already did?

You may have signed in with a different account than the one you used when you saved your permanent copy. Check whether you are in Google, GitHub, Clever, or Harvard Google with the same account you used before. If you still cannot find the project, contact the teaching team with the account type you used and a screenshot of your Posit Cloud workspace.

I clicked the class project link again and my work is gone. Where is it?

The class project link creates a new temporary copy every time it is opened, so the project you are looking at is brand new. Your work is still in your saved copy. Close the temporary copy, go to posit.cloud, sign in with the same account as before, and open your project from Your Workspace.

To avoid this, use the class link only once. After you save a permanent copy, always enter through Your Workspace.

Can I do the assignments on my phone or tablet?

Use a computer for the actual work. This guide reads fine on a phone, but Posit Cloud needs a laptop or desktop browser to edit and knit the .Rmd files comfortably.

Using Posit Cloud

What are the main parts of the Posit Cloud interface?

Posit Cloud uses the same basic layout as RStudio. The editor is where you write in the assignment .Rmd file. The console runs quick R commands. The environment pane shows objects you have created. The files pane shows folders and files in the project, including the assignments folder.

How do I run code chunks in R Markdown?

Put your cursor inside the chunk and click the green run arrow in the upper-right corner of the chunk. You can also use Cmd + Shift + Enter on Mac or Ctrl + Shift + Enter on Windows.

What if my Posit Cloud project becomes idle?

Save your work, then resume or reopen the project. You may need to reload packages or rerun earlier chunks, but saved files should remain in your project copy.

R Markdown files

What are the R Markdown files?

The R Markdown files combine instructions, code chunks, and short written answers. Open each assignment file in order, write your code and responses directly in that file, and knit regularly to check that the document still runs.

Why do I need to knit?

Knitting runs the whole assignment from top to bottom in a fresh R session. This is different from running chunks manually in any order. A successful knit shows that your code, output, and written answers can be reproduced.

Why does knitting say an object like hks_blue was not found?

Each assignment knits on its own in a fresh R session. Objects you created while working in another assignment, such as a custom color object from Part 3, do not automatically exist in Parts 4 or 5.

If you reuse code from an earlier assignment, make sure any custom objects it needs are also defined in the current .Rmd file before the plot or table code runs.

Do I submit HTML files?

No. HTML files may be created when you knit, but the file you submit is the completed .Rmd file for each assignment.

Which file format should I download?

Download the completed .Rmd file. That is the file you will submit to Canvas.

Common knitting errors

Most knitting failures are one of these five. Read the error message slowly, find the matching row, and try the first fix before asking for help.

Error message decoder

The error says It usually means First thing to try
object 'x' not found The file uses an object that is never created inside this .Rmd. Knitting starts from a fresh R session, so objects from the console or another assignment do not exist. Create the object earlier in the same file, then knit again.
could not find function "filter" The package that provides the function is not loaded in this file. Check that library(tidyverse) runs in the setup chunk at the top of the file.
cannot open file '…csv' The path to the data file is wrong, or the file was moved or renamed. Use the original path ../data/development_indicators_2026.csv and keep the assignment file inside assignments.
unexpected '}' or unexpected symbol A parenthesis, bracket, quote, or comma is unbalanced somewhere at or above the line R reports. Go to the reported line and check the lines just above it. Count the ( ) pairs and the quotes.
Chunks run fine, but knitting fails You ran chunks in a different order than they appear in the file. Knitting only runs top to bottom. Restart R, then run all chunks from the top in order to find the first one that breaks.

Data

Where do the assignment data come from?

The assignments use one cleaned country-year CSV snapshot created for this course. Most indicators come from the World Bank World Development Indicators. Governance indicators come from the Worldwide Governance Indicators. The data dictionary lists the exact source, indicator code, unit, and notes for each variable.

Why are some values missing?

Missing values are normal in development data. Some indicators, such as population and life expectancy, are available for nearly every country-year. Poverty and inequality indicators often depend on household surveys, so they are measured less frequently. The assignments ask you to notice and explain missingness rather than ignore it.

Why do the filters need to be coherent?

A filter should match a real policy question. For example, it makes sense to filter to Sub-Saharan Africa and then choose countries from that region. It does not make sense to filter to Sub-Saharan Africa and then ask for India, because that would return no rows.

When you combine filters, check the intermediate data. If you filter to a region first, list the countries in that region before adding a country filter.

AI use

Can I use ChatGPT or similar tools?

AI tools can help explain error messages or clarify what a specific R command does. They should not choose your answers, replace your practice, or write interpretations you cannot defend. You are responsible for understanding and checking all code and written work you submit.
