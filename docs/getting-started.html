Getting started

Work in Posit Cloud

The website gives you the sequence and support materials. The actual assignment files are in the Posit Cloud project.

Open Posit Cloud Start the warm-up

First steps

  1. Sign in to Posit Cloud with a Google, GitHub, or Clever account.
  2. Open the API-209 summer assignments project.
  3. Save a permanent copy to your own workspace before editing.
  4. Open the assignments folder in the Files pane.
  5. Complete the five .Rmd files in order.

Folder structure

In Posit Cloud, the assignment project contains an assignments folder with five R Markdown files: 

/summer-assignment
  assignments/
    R Summer Assignment 1.Rmd
    R Summer Assignment 2.Rmd
    R Summer Assignment 3.Rmd
    R Summer Assignment 4.Rmd
    R Summer Assignment 5.Rmd

Open each file in Posit Cloud. Write code and short answers directly in the file, then knit regularly to check your work.

Tools

Posit Cloud

Posit Cloud is the browser-based RStudio environment for the summer assignments. It lets you edit, run, save, and download the assignment files without installing software.

R and RStudio

R is the programming language used for the assignments. RStudio is the interface you use to write and run R code. Posit Cloud gives you RStudio in your browser.

R Markdown

R Markdown combines instructions, code, output, and written responses. The completed .Rmd file is what you submit.

Before Part 1

If you have never used R before, start with the warm-up. It introduces the habits you will use in the assignments: read the code, predict the result, run it, and explain what happened.
