Submission

Submit the completed R Markdown files

For each part you submit one completed .Rmd file on Canvas — the same file whether you worked in your browser or in Posit Cloud.

If you worked in your browser

  1. On the assignment page, type your name in the panel so the file is named R Summer Assignment N - First Last.Rmd.
  2. Run your chunks from top to bottom and fix any error or warning — the exported file contains your code exactly as written.
  3. Press Download my .Rmd. That downloaded file is what you submit (and your backup — keep it).

Haven't downloaded yet? Open your part: Part 1 · Part 2 · Part 3 · Part 4 · Part 5

If you worked in Posit Cloud

Before downloading from Posit Cloud:

  1. Confirm that you are in your own saved Posit Cloud copy, using the same account you used while completing the assignment.
  2. Add your name in the YAML header at the top of each assignment file, replacing YOUR NAME.
  3. Run the chunks you completed and knit the file. Knitting runs the assignment from top to bottom in a fresh R session, which checks that the work is reproducible.
  4. Review your written answers and make sure you can explain each result you submit.
  5. Complete the AI-use note. In Part 5, complete the fuller AI-use reflection.

Download from Posit Cloud

Submit the file ending in .Rmd, not the knitted .html file. In the Files pane, select the assignment file whose name ends with .Rmd.
  1. Open your saved copy from Your Workspace (not the class project link).
  2. In the Files pane, open the assignments folder.
  3. Tick the checkbox next to the completed .Rmd file.
  4. Click More (the gear) and choose Export...
  5. Rename the downloaded file with your name, for example R Summer Assignment 1 - First Last.Rmd.

Repeat this process for each of the five assignment files.
