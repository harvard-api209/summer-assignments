Missing values in summaries

Some indicators have missing values. By default, mean() returns NA if any input value is missing.

dev |>
  filter(assignment_sample == TRUE & year == 2023) |>
  summarise(mean_poverty = mean(poverty_rate))
## # A tibble: 1 × 1
##   mean_poverty
##          <dbl>
## 1           NA

Use na.rm = TRUE to remove missing values from the calculation.

dev |>
  filter(assignment_sample == TRUE & year == 2023) |>
  summarise(
    mean_poverty = mean(poverty_rate, na.rm = TRUE),
    countries_with_poverty_data = sum(!is.na(poverty_rate)),
    total_countries = n()
  )
## # A tibble: 1 × 3
##   mean_poverty countries_with_poverty_data total_countries
##          <dbl>                       <int>           <int>
## 1         11.5                          26             116

Missingness is substantive. Poverty data are usually based on household surveys, which are not available every year in every country.

Mean versus median

Means can be sensitive to outliers. Medians are often useful for skewed variables like GDP per capita.

dev |>
  filter(assignment_sample == TRUE & year == 2023) |>
  group_by(region) |>
  summarise(
    mean_gdp_pc = mean(gdp_per_capita_ppp, na.rm = TRUE),
    median_gdp_pc = median(gdp_per_capita_ppp, na.rm = TRUE),
    n_countries = n(),
    .groups = "drop"
  )
