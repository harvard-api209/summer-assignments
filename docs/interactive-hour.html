Warm-up 1

Run code and read the output

In the assignments, you will work in R Markdown files. A code chunk is a small block where R commands live. When you run a chunk, R prints output below it. Start by reading one line at a time. 

12 + 2

Predict

If you run this line, what will R print?

Warm-up 2

Objects: putting a name on a value

In R, the arrow <- saves something with a name. Once the object exists, you can use the name instead of typing the value again. Objects can store numbers, words, logical values like TRUE or FALSE, and longer collections of values. 

1year <- 2026
2program_cost <- 125000
3country <- "Ghana"
4
5program_cost

Predict

What will R print when line 5, program_cost, runs?

Warm-up 3

Functions: commands with inputs

A function does something. The inputs go inside parentheses. In public policy work, a function might calculate an average, count observations, or make a graph. 

1program_costs <- c(120, 150, 180)
2mean(program_costs)

Choose the output

What does mean(program_costs) return?

Warm-up 4

Data frames: rows, columns, and units

A data frame is a table. Before calculating anything, ask what one row represents. That is the unit of analysis.

country year poverty_rate
Ghana 2023 23.4
Ghana 2024 22.8
Kenya 2024 19.6

Check the unit

What does one row represent?

Warm-up 5

Pipes: reading code left to right

The pipe |> sends the result of one step into the next step. This is helpful because data analysis usually happens as a sequence: start with a dataset, keep some rows, create or select columns, summarize, then plot or interpret.

Read piped code from top to bottom. The first line is the starting object. Each later line is one action applied to the result so far. When you are confused, translate each line into a short sentence.

You do not need to know filter() or arrange() yet. For now, practice reading each line as a plain-English action. 

1poverty |>
2  filter(country == "Ghana") |>
3  arrange(year)

Worked example

  1. Start with the poverty data.
  2. Keep rows where country is Ghana.
  3. Sort the remaining rows by year.
1schools |>
2  filter(district == "Boston") |>
3  arrange(desc(year))

Your turn

Which plain-English version is closest?

Warm-up 6

Errors and surprises: slow down and locate the problem

An error or unexpected result is information. The first task is not to panic. The first task is to find what R was trying to do. 

1poverty_rate <- c(23.4, NA, 19.6)
2mean(poverty_rate)

[1] NA

Diagnose

Why did R return NA?

Warm-up 7

AI: ask for help you can verify

AI can be useful when your question is specific and checkable. It is much less useful when it replaces your own explanation.
