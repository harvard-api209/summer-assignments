Warm-up 1

Objects: putting a name on a value

In R, the arrow <- saves something with a name. Once the object exists, you can use the name instead of typing the value again. Objects can store numbers, words, logical values like TRUE or FALSE, and longer collections of values.

Warm-up 4

Pipes: reading code left to right

The pipe |> sends the result of one step into the next step. This is helpful because data analysis usually happens as a sequence: start with a dataset, keep some rows, create or select columns, summarize, then plot or interpret.

Read piped code from top to bottom. The first line is the starting object. Each later line is one action applied to the result so far. When you are confused, translate each line into a short sentence. 

1population |>
2  filter(country == "France") |>
3  arrange(year)

Worked example

  1. Start with the population data.
  2. Keep rows where country is France.
  3. Sort the remaining rows by year.
1elections |>
2  filter(state == "MA") |>
3  arrange(desc(year))

Warm-up 5

Errors: slow down and locate the problem

An error is information. The first task is not to panic. The first task is to find what R was trying to do. 

1mean(c(10, 20, NA))
