The coding assignments

Five parts, one cleaned country-year development dataset. Each part opens in its own tab, runs entirely in your browser — nothing to install, no account — and exports a completed .Rmd file for Canvas. Your work saves automatically in this browser, and the downloaded file is your backup.

Prefer RStudio? The identical assignments live in the Posit Cloud project. Either way, you submit the same .Rmd file.

How the browser assignments work

Run

Real R, in the page

Each code chunk is editable and runs real R in your browser. Parts 2–5 load the course dataset automatically; the first chunk installs the tidyverse, which can take a few minutes once.

Save

Autosave, per browser

Your code and answers save automatically — but only in this browser on this device. Download your .Rmd whenever you stop working; that file is your real backup.

Check

No errors, no warnings

Before you download, run your chunks from top to bottom and fix anything that prints an error or warning. The exported file contains your code exactly as written.

Submit

One file to Canvas

The exported .Rmd is the same file a Posit Cloud student submits. Add your name in the panel so it lands in the filename, then follow the submission steps.

Prefer Posit Cloud or RStudio?

The same five assignments live in the Posit Cloud project with the same dataset and the same submission format. Use whichever environment suits you; the teaching team grades the same .Rmd either way.
