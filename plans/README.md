## Findings considered and rejected

- **De-duplicate nav/footer markup across the 7 HTML pages via JS
  injection**: would break the deliberate no-JS fallback for ~30 lines of
  duplication that changes twice a year. Not worth it.
- **"7 steps everywhere" as the unification scheme** (alternative to "5
  parts"): rejected because the assignments are externally branded as
  five parts (file names, Canvas, professor's language); inflating the
  count with setup/warm-up is what caused the confusion.
- **Renaming "Posit Cloud" in prose to platform-neutral wording**: the
  course does use Posit Cloud; hedged prose would be vaguer for students
  without making a swap easier. Link centralization (plan 002) buys the
  real flexibility.
